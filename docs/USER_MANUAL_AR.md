# دليل المستخدم — DRS Bot Host v1.0

> التطبيق يجعل هاتفك أندرويد **سيرفر بوتات صغيرًا**: تستورد بوتات بايثون
> (ZIP أو مجلد)، تشغّلها في الخلفية، وتراقب سجلاتها لحظيًا — بلا أي سيرفر
> خارجي أو اشتراك مدفوع.

## 1. التثبيت

1. احصل على ملف APK (من GitHub Actions أو ببنائه محليًا — انظر BUILD_GUIDE).
2. افتح الملف واسمح بالتثبيت من المصادر غير المعروفة إن طُلب منك.
3. عند أول فتح سترى أربع تبويبات: الرئيسية / البوتات / استيراد / الإعدادات.

## 2. استيراد أول بوت

1. تبويب **استيراد** → «اختيار أرشيف ZIP» أو «اختيار مجلد المشروع».
2. اختر بوتًا يلتزم بمواصفة BOT_SPEC (تجربة جاهزة: `sample-bots/echo-bot.zip`
   — اضغطه من المستودع أو استورد مجلد `sample-bots/echo-bot` مباشرة).
3. لو كان المعرّف مستخدمًا فعّل خيار «استبدال بوت موجود».
4. عند النجاح تنتقل مباشرة إلى شاشة البوت.

رسائل الأخطاء توضح السبب بالضبط (بيان ناقص، امتداد محظور، حجم يتجاوز
الحدود…) — كلها من مدقق الاستيراد المُختبر.

## 3. التشغيل والمراقبة

- زر **تشغيل** يبدأ البوت؛ الحالة تتغير: يبدأ → يعمل.
- **السجلات المباشرة** أسفل شاشة البوت تتدحرج تلقائيًا (وقت/مستوى/رسالة).
- لو انهار البوت مع سياسة `on_failure` سترى حالة «إعادة تشغيل مجدولة»
  ثم محاولة جديدة تلقائية، مع عدّاد إعادة المحاولات.
- زر **إيقاف** يطلب من البوت التوقف بلطف (البوتات التعاونية تخرج خلال
  ثوانٍ)، و**إعادة تشغيل** تدمج الإيقاف والتشغيل.

## 4. إبقاء البوتات حية

من تبويب **الإعدادات**:

1. **تجاهل تحسينات البطارية** — مهم جدًا؛ بدونه قد يجمّد أندرويد الخدمة
   بعد فترة. اضغط الزر ووافق.
2. **إبقاء المعالج نشطًا** — يحتفظ بقفل تنبيه جزئي (يستهلك بطارية أكثر).
3. **تشغيل الخدمة عند إقلاع الجهاز** — يعيد الاستضافة بعد إعادة التشغيل.
4. **تشغيل البوتات المعلمة بـ auto_start** — يشغّل البوتات المؤهلة مع بدء
   الخدمة (انظر bot.json في BOT_SPEC).

وعند بدء **خدمة الاستضافة** من الرئيسية، يظهر إشعار دائم يعرض عدد
البوتات العاملة مع زر «إيقاف كل البوتات».

## 5. كتابة بوت خاص بك

أقصر مثال صحيح:

```
my-bot/
├── bot.json
└── main.py
```

```json
{
  "id": "my-bot",
  "name": "My Bot",
  "version": "1.0.0",
  "entrypoint": "main.py"
}
```

```python
from drs_host.sdk import get_context

ctx = get_context()
while not ctx.should_stop:
    ctx.logger.info("hello from my phone")
    ctx.sleep_or_stop(10.0)
```

اضغط المجلد ZIP واستورده. التفاصيل الكاملة (سياسات الإيقاف، config،
التقدم، القيود) في `docs/BOT_SPEC.md`.

## 6. أسئلة متكررة

**البوت يقف عند STOPPING ولا يخرج؟** بوتك لا يفحص الإيقاف — اجعله
تعاونيًا عبر `sleep_or_stop`/`should_stop` (BOT_SPEC §3).

**بوت يستخدم مكتبة خارجية (requests…) ويقول «حزم ناقصة»؟** حزم pip
تُدمج عند بناء APK — أضفها في gradle وأعد البناء (BOT_SPEC §6 وBUILD_GUIDE).

**أين ملفات بوتاتي؟** داخل مسار التطبيق الخاص: `filesDir/botdata/bots/<id>/`،
والسجلات الدائمة في `logs/runtime.jsonl` داخل كل بوت.

**هل تُرسل بياناتي لأي مكان؟** لا. لا يوجد أي سيرفر؛ كل شيء على الهاتف.
